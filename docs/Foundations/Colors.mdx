# Colors

Color tokens are **semantic**: the name says what a color is *for* (a surface, the content on it, an outline), not what it looks like.
They use the same names as the Figma variables (`SurfaceHover` → `--ds-color-surface-hover`), so design and code share one vocabulary.

The Figma components use only semantic variables, so the tokens hold the hex values directly.
Different roles can share a value: `Inverse` and `OnNeutral` are both `#1b2134`, one as a background and one as text, and each can change without the other.

Everything on this page is read from the loaded stylesheet (`src/styles/tokens.scss`): adding a token there makes it appear here.

## Contrast

WCAG contrast of the color pairs used by the components, computed from the tokens.
Text needs at least **4.5:1** ([WCAG 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum)),
graphical objects needed to understand a component **3:1** ([WCAG 1.4.11](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast)).
