# Design System — Tabs

An accessible, reusable **Tabs** component with **Badge**, built as part of a small design system: React 19, SCSS Modules written from scratch, design tokens as CSS custom properties. It answers the [home test brief](https://github.com/primait/fe-interview-design-system/blob/master/src/Introduction.mdx) and follows the [Figma file](https://www.figma.com/design/OclakAGLSXDoMKLFvwLNMP/?node-id=47-678).

## What's inside

- **Foundations:** [Colors](?path=/docs/foundations-colors--docs) (with contrast ratios), [Typography](?path=/docs/foundations-typography--docs) and [Spacing](?path=/docs/foundations-spacing--docs), generated from the design tokens.
- **Components:** [Tabs](?path=/docs/components-tabs--docs) and [Badge](?path=/docs/components-badge--docs), each with design and tech guidelines, props, keyboard and screen reader notes.

## Acceptance criteria

| As a developer, I want to… | Where |
|---|---|
| switch between the variants of the `Tabs`, according to the design | `variant="pill" \| "underline"` on `Tabs`: [Variants story](?path=/story/components-tabs--variants) |
| add a `Badge` to a `Tab` using the Tab's API | `badgeProps` on `Tab`: [With badges story](?path=/story/components-tabs--with-badges) |
| choose between different `Badge` variants | `badgeProps.variant`: `neutral`, `positive`, `negative` ([Badge](?path=/docs/components-badge--docs)) |

## Quick start

```tsx
// Optional: the Inter font, served by your app (needs @fontsource-variable/inter).
import "<design-system>/fonts";
import { Tab, TabList, TabPanel, Tabs } from "<design-system>";

<Tabs defaultValue="emails">
  <TabList aria-label="Inbox">
    <Tab value="emails">Emails</Tab>
    <Tab value="files" badgeProps={{ label: "Warning", variant: "negative" }}>
      Files
    </Tab>
  </TabList>
  <TabPanel value="emails">…</TabPanel>
  <TabPanel value="files">…</TabPanel>
</Tabs>
```

`<design-system>` stands for the package name: the design system is not published yet. In this repository the entries are `src/index.ts` (components and tokens) and `src/fonts.ts`.

## Principles

- **Accessible by default:** the WAI-ARIA Tabs pattern (roles, keyboard, focus management), with automated accessibility tests (axe).
- **Composable:** compound components (`Tabs`, `TabList`, `Tab`, `TabPanel`), controlled or uncontrolled, with native props, `ref` and `className` passed through.
- **Themeable with tokens:** redefine the `--ds-*` custom properties on any wrapper.
- **A small, stable styling API:** one `ds-*` class per part and `data-*` state attributes, with a documented specificity contract. Internal classes are private.
- **Zero runtime CSS:** SCSS Modules compiled to static CSS.
